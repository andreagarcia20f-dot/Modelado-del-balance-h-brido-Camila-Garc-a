# Modelado del balance híbrido de una micro-red

## Descripción

Este proyecto corresponde a la simulación de una micro-red híbrida
utilizando MATLAB.

El modelo considera:

- Generación de energía solar.
- Generación de energía eólica.
- Generación total híbrida.
- Demanda de energía de la comunidad.
- Comparación entre generación y demanda durante 24 horas.

## Herramienta utilizada

MATLAB R2026a
